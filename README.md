# Titanic Dataset: Data Visualization

## Objective
To transform the Titanic passenger data into clear visuals that reveal who survived and why.

## Dataset
891 passengers, 12 variables.
Source: https://github.com/datasciencedojo/datasets

## Visualizations
- Overall survival (pie chart)
- Survival rate by passenger class and gender (grouped bar chart)
- Age distribution by survival status (histogram)
- Ticket fare by passenger class (box plot)
- Survival rate by port of embarkation (bar chart)
- Summary dashboard combining the key views

## Key Insights
- About 38% of passengers survived.
- Women survived at about 74% versus about 19% for men.
- Survival declined with passenger class: 63%, 47%, 24%.
- Children had the highest survival rate among age groups.

## Tools Used
Python, Pandas, NumPy, Matplotlib, Seaborn

## How to Run
Open `Titanic_Visualization.ipynb` in Google Colab and select Runtime > Run all.
